# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
- 工人：`LISTEN/NOTIFY` 唤醒后认领
- 前端：Vue 3、Vite、nginx 反代 `/api`

## 午休稀采灯

午休时段样本稀少，给值班亮一盏提示灯。**灯只做提示，永不拒收**：提交与写入通道任何时候都放行。

- 判定链路：后台时钟 → 亮灯判定 → 写入通道（工人每个轮询周期先判灯再认领，认领绝不看灯）。
- 亮灯条件（须同时满足）：后台记下的时刻（北京时间）落在午休窗内，且近窗办结条数低于阈值；灯态翻转时记一条履历。
- 页面：顶栏「午休稀采」专页，展示午休起止、最低办结条数、近窗办结数与亮灯履历；扫描员可改阈值，观察员只读。

| 接口 | 方法 | 权限 | 说明 |
|------|------|------|------|
| `/api/lunch-lamp` | GET | 登录 | 灯态、判定时刻、阈值、近窗办结数 |
| `/api/lunch-lamp/config` | PUT | 扫描员 | 改午休起止（HH:MM）、最低办结条数、近窗分钟数 |
| `/api/lunch-lamp/events` | GET | 登录 | 亮灯/熄灭履历（最近 100 条）|
